Як користуватися системою звітів

  1. Перейдіть до "Новий звіт" у верхньому меню.
  2. Виберіть дату звіту та регіон.
  3. Заповніть загальний опис регіону (необов’язково).
  4. Скористайтеся Додати звіт по групі, щоб ввести дані по групах:
    • Виберіть назву групи (залежно від обраного регіону).
    • Виберіть місця та підрядників, пов’язаних із цією групою.
    • Укажіть, чи працювала група, чи ні.
    • За бажанням додайте втрати та додаткові дані для групи.
  5. За потреби додайте загальні додаткові дані.
  6. Натисніть Надіслати звіт, щоб зберегти дані.
